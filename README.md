# 学习工具箱（Edge 扩展）

一个面向学习通与浙学的浏览器工具箱，把常用的页面辅助、题目处理和章节学习能力集中到悬浮面板中。项目使用 TypeScript + Manifest V3，构建后可直接在 Edge / Chrome 中加载。

> 本项目是个人学习辅助工具，与学习通、浙学官方无关。请遵守所在学校和平台的使用规定，自行承担使用风险。

## 支持范围

**0.4.1 API 页面重设计**：按模型列表管理接口，可直接启停、上移/下移优先顺序、编辑、测试、移除和撤销。地址与 Key 收入独立编辑窗；取消恢复当前模型，关闭后清空编辑框密钥。列表更改须显式保存，测试只调用选中的已保存模型。页首用量卡片展示所有模型合计的已知费用、预算环、预算剩余、请求次数及输入/输出 Token；不是服务商账户余额。价格、记录和备份设置默认折叠，支持窄屏。

**0.4.0 候选版**：合并下列 A/B/C 批能力，增加离线中英文 OCR、扫描/混合 PDF 与图片导入，以及 DOCX 表格/基本编号/上下标/简单分式和文字 PDF 分栏提取。支持来源预览、页码范围、阅读顺序、百分比截取、逐页进度和取消；校对固定格式并确认后才能入库。复杂公式和不可读取对象保留待转写标记；跨页仍属于需要真实平台验证的实验功能。

| 新增能力 | 入口与当前验证范围 |
| --- | --- |
| 跨页处理、保存确认 | 答题区“当前页及后续页”，构造双页流程通过，真实双平台待验证 |
| 收藏与错题本 | 题目详情快捷收藏；设置页管理笔记、标签和掌握状态，隔离 Edge 通过 |
| 题库条目编辑 | 题库详情编辑、历史、撤销和版本冲突保护，迁移及 UI 验证通过 |
| 思维阶梯本地联动 | 共用来源和选库，可只搜题或显式填写，无 Key 本地流程通过 |
| 相似题参考 | 已选题库内最多 5 条，展示差异；人工参考，不自动填写 |
| 本地 OCR | 中英文图片、扫描/混合 PDF、DOCX 内嵌图片，隔离 Edge 断网验证通过 |
| 复杂文档导入 | 基本表格/编号/上下标/分式、PDF 分栏、区域与页码；复杂对象人工转写 |

**0.3.11 C 批实验适配**：答题工作区新增“当前页及后续页”。先检查稳定试卷标识、页码与唯一原生下一页入口；填写模式要求本页完整回读及新的草稿保存确认，只搜题模式不保存。分页重复、保存未确认、换卷或未知入口时停留。标签页会话保留已处理页的摘要，可显式恢复；完整跳转/刷新后先核验本页，已处理页不重复填写。最小化条可暂停跨页。当前仅通过本地构造页面验证，学习通与浙学的真实可编辑路由、保存反馈仍需实测；不自动交卷。

**0.3.10 B 批候选版**：思维阶梯接入同一答案来源服务，支持选库、本地优先、只搜题/自动填写与显式应用参考答案；本地命中不需要 API，仍保护人工编辑和过期题库结果。普通题目和思维阶梯新增“相似题参考”，仅搜索已启用且当前选择的库，展示题干/选项/关键条件差异；不自动填写，不把排序当正确率。MiniSearch 使用中文字二元组及保留大小写的英文/数字词元，本地索引按库版本失效。

**0.3.9 A 批候选版**：题库详情新增单题编辑、并发版本检查、修改记录与撤销；题目详情新增收藏与手动错题标记。设置页“题库管理”可管理收藏、标签、笔记与掌握状态，导出 TXT 或完整题库/收藏 JSON，预览确认后原子恢复。收藏独立于短期搜题历史；删除原题库仍保留收藏快照。题面图片只保留需回原页核对的提示。完整备份恢复会替换现有题库与收藏；单库旧版 JSON 导入继续支持。

**0.3.8 是候选版**：增加复检结果复用、AI 答案差异标记、多模型优先级、DeepSeek/MiMo 快速配置、预算用量环和文本题精简输出；保留本机搜题历史、多格式题库、漫画风、小悬浮点、倍速和当前内容起点。真实可编辑考试的路由、保存与分页仍需实机证据；本版不会自动返回或交卷。

## 模型、预算与复检

在“设置 → AI 与用量”管理最多 10 个模型。每个模型独立保存地址、Key、模型 ID、图片能力、启用状态和优先级。列表上移/下移会重新排列优先级；编辑窗也可填写数字，越小越优先，同优先级按列表顺序。每次选一个已启用且已授权的模型，图片题按能力筛选；失败时暂停供人工处理。启停、排序和移除通过“保存列表更改”生效，移除可撤销；编辑窗“保存更改”同步保存列表，取消只回滚本次模型编辑。预设不会带走其他模型的密钥，测试只请求所选已保存模型，存在待保存配置时先保存。

“快速配置”新建空 Key 的模型草稿。按用户指定，DeepSeek 1017 默认实际 `model` 为 `deepseek-v4.1-flash-1017`，请确认你的接口支持该 ID；另有官方别名 `deepseek-flash` 预设，官方文档截至 2026-11-07 将其映射到 V4.1-Flash-1017。ID 可手动编辑并原样发送，不自动替换。[DeepSeek 官方更新记录](https://api-docs.deepseek.com/updates/)

MiMo 预设使用 V2.6 Flash / Pro；按量入口为 `https://api.xiaomimimo.com/v1`，Token Plan 独立入口为 `https://token-plan-cn.xiaomimimo.com/v1`，须填写对应 Key。模型与接口均可手动修改。[MiMo 官方版本说明](https://mimo.mi.com/docs/zh-CN/news/latest/v2-6)、[调用说明](https://mimo.mi.com/docs/en-US/quick-start/summary/first-api-call)

各模型可分别设置输入、缓存输入和输出单价；同接口同模型共用价格，其他模型的单价保留。所有模型共用本轮统计与预算，改变优先级保留统计，更改单价开启新一轮。预算环显示**已知预计费用 / 本机自设预算**；未设预算、存在未知费用、进行中请求及超限分别展示。金额以账单为准，预算环不表示账户余额或 MiMo Token Plan Credits。

“AI 整卷复检”分为本地读取、一次 AI 请求、返回后本地核验三个阶段。同页相同题目和答案再次点击复用最近的复检结果；本页最多保留三份快照，刷新清除。确认“重新请求 AI”才强制发起新请求；配置、题目和答案变化会重新核对。红色 **≠** 表示当前完整答案和 AI 建议不一致，详情并列展示两份答案；橙色表示 AI 不确定。普通 AI 搜题也参与完整答案比较，多选仅顺序不同不会误报。人工修改后点击“刷新阅览”更新比较，复检本身不修改页面答案。

文本填写题会在同一次生成中要求模型先归纳，再输出精简最终答案：保留得分点、否定条件、数字、单位、公式及必要步骤。题干明确的字数、论述深度、引用与步骤要求优先，程序代码保持完整。此行为通过生成指令实现，仍需人工核对模型实际输出；不按字符数强制截断，也不另发付费总结请求。

旧单模型配置会在读取时兼容，首次保存列表升级；新备份包含全部模型、优先级和明文 Key，并兼容旧单模型备份。回退旧插件前请先导出配置，新多模型格式不保证被旧版读取。

- **浏览器**：Edge / Chrome 119 及以上，Manifest V3。
- **站点**：学习通相关域名（`*.chaoxing.com`）与浙学（`www.zjooc.cn`），匹配规则见 `src/shared/sites.ts`。
- **页面**：只处理当前已加载的题目；未加载、分页或平台禁止编辑的内容不会处理。
- **边界**：不自动交卷，不自动点击程序题的“运行”，不绕过平台的考试限制；章节测验的自动提交遵循章节学习设置。

| 功能 | 学习通 | 浙学 |
| --- | --- | --- |
| 章节学习 | 保留视频、课件与章节测验联动 | 保留视频、课件与平台完成确认 |
| 题目处理 | 保留已有题型、题库/AI、导入与复核，增加独立搜题 | 补真实回看结构；已支持路由上的单选、多选、判断、普通文本控件保持候选适配，真实可编辑页待验证 |
| 展开 / 最小化 / 悬浮入口 | 支持 | 支持 |
| 独立作业/考试交卷 | 用户手动操作 | 用户手动操作 |

浙学未能识别题目时会显示原因，保留刷新和手动处理入口。当前只处理已加载范围，不自动跨未知分页，不将题目数量当作整卷加载完成的证据。

## 界面与任务控制

- 漫画风使用统一的纸白、墨线、黄蓝色块和实色阴影，设置页、扩展弹窗和网页浮窗共用设计令牌。
- 点击标题栏的减号最小化为迷你控制条；保留状态、进度、暂停/继续、展开和更多。更多菜单中可隐藏为悬浮入口、打开设置、复位位置。
- 点击悬浮入口恢复隐藏前的展开或最小化状态；收起、隐藏和恢复均不会启动或停止任务。
- 悬浮点直径 24px，点击和拖动区域 32px；保留缩小的运行状态角标。
- 运行中的主操作固定在面板底部，正文独立滚动；外部 AI 与本地题库默认折叠。
- 暂停作用于插件处理，平台考试计时仍继续；填写回读成功与平台保存成功分别核对。
- 同一识别试卷地址的处理会话互斥；另一个标签页需要先暂停或关闭占用页。不同 URL 变体是否属于同一试卷仍需实机核实。

**浙学播放倍速**：进入课程视频页后，在“章节学习”的自动学习开关下选择“播放倍速”。默认保留“平台最高”；其他选项从当前播放器菜单读取，例如 1、1.25、1.5、2、4 倍，具体以当前视频为准。选择会自动保存并在播放中应用，后续视频沿用；修改倍速不会启动或恢复已暂停任务。若下一段视频不提供所选值，保持原生实际播放并提示重新选择，不假报已经应用。

还没有倍速选项时，先进入视频并手动播放一次，让平台初始化菜单。学习通保留现有独立倍速控件。更新已有安装时，先在扩展页点击“重新加载”，再刷新课程页。

**浙学学习起点**：在“播放倍速”下将“学习起点”选为“从当前内容往后”，再点击“从当前内容开始”。新任务从当前选中的视频或课件向后处理，同节之前的内容和较早章节都跳过；前面的未完成项不阻挡本次范围，也不会被标记为完成。默认的“首个未完成内容”仍保留。

普通“继续学习”、迷你条继续和同一标签页刷新都沿用本次保存的起点与位置。手动换页后需要重新定位时，再点“从当前内容开始”；只修改下拉选项不会改变正在运行或暂停的任务。页面尚在加载时等待当前内容就绪，定位期间切页或保存的目录/内容已变化时暂停并提示重新定位，不回退到第一节。会话使用浏览器的临时会话存储，关闭标签页或重启浏览器后需重新选择起点。学习通保留原有“从当前章节向后”的章节级起点设置。

## 导出题目与答案

在学习通或浙学的题目结果区，找到“导出格式”，选择 TXT 或 JSON，再点“导出题目与答案”。文件包含当前列表已加载的题号、题型、题干、选项、已获取答案、页面答案、来源、处理状态和复检建议；未获取或仍在生成的结果会明确标记。任务运行中也可导出当时的快照，导出不调用 AI、不改写页面，也不翻页获取额外题目。

TXT 使用 UTF-8 BOM，便于 Windows 直接阅读；JSON 保留结构化信息，使用独立的 `question-results` 格式，不等同于现有导入面板的答案包或题库包。选项答案同时显示字母与内容；程序代码保留换行，图片保留链接，内嵌图片标记为回原页查看。获取的答案与人工改过的页面答案分别保留，不把已填写当作平台已保存或答案正确。本页结果可导出完整快照；纯文本完整参考答案另按搜题记录设置保存在本机，刷新后需要显式恢复。

## 安装

推荐 Node.js 24；最低 Node.js 22.13：

```bash
npm ci
npm run build
```

然后在 `edge://extensions` 加载生成的 `dist/`。常用命令：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 监听源码变化并重新构建 |
| `npm run typecheck` | 类型检查 |
| `npm run lint` | 代码检查 |
| `npm test` | 题目处理、任务控制和位置规则的行为回归 |
| `npm run check` | 依次执行类型检查、Lint、行为回归和构建 |
| `npm run package` | 检查、构建并生成发布 ZIP |

修改源码后需要**重新构建 → 在扩展页重载扩展 → 刷新目标网页**，三步缺一不可。

## 使用

1. 打开学习通或浙学页面，点击扩展图标，或使用页面上的悬浮工具箱。
2. 在答题面板选择答案来源。首次使用 AI 时，先在设置页填写接口地址、模型和 API Key。
3. 点击“识别当前页”或“刷新题目”读取当前已加载题目；“处理当前页”会逐题处理，已有答案默认保留。
4. 需要复核时使用“AI 整卷复检”。复检只标记疑似问题，不修改页面答案。
5. 程序题会读取页面语言和代码编辑器，写入后调用页面自身的保存逻辑；插件不会自动运行代码，提交前请自行运行核对。

**外部 AI**：可以复制当前题目和格式要求，交给其他模型；再把返回的 JSON 粘贴回来解析填入。  
**本地题库**：在“设置 → 题库管理 → 我的题库”管理，见下文。

## 浙学搜题与自动填写

1. 进入题目页，点击“识别当前页”。成绩回看页自动使用“只搜题”，不会解除禁用的控件。
2. 配置来源或选择本地库。“只搜题”可检索已答题、未答题和回看题；卡片的“搜本题”会重新检索该题。
3. 范围可选“当前已加载全部题”“仅本题”“当前题及后续”。当前题由题号导航选中；更改模式、范围和来源不会启动请求。
4. “自动填写”只用于可编辑且已适配页面，默认保留已有答案。搜索结果可点击“应用本题答案”，有内容时需确认覆盖；搜索后人工修改、删库、来源变更或换题会阻止旧结果应用。
5. 暂停保留本页完整结果，继续复用已获取答案；关闭或刷新结束本次内存会话，重新识别后可显式恢复匹配的本机参考结果。切换范围按新起点处理。
6. 回看单独显示“我的答案 / 得分 / 平台解析”，不当作标准答案直接入库。TXT/JSON 包含已读取的回看信息；搜索只发送题干和选项等必要内容。
7. 默认处理当前已加载题目。可单独启动实验功能“当前页及后续页”，只有稳定试卷身份、明确页码及唯一原生入口均通过检查才继续；填写模式须收到新的草稿保存确认后翻页。真实平台保存/分页信号仍需验证，未识别时停留，最终交卷由用户操作。

## 搜题记录、用量与异常处理（0.3.7）

- 题目区“本机搜题记录”提供匹配数量、“恢复匹配记录”和经确认的本页删除。只保存完整纯文本参考答案、来源、时间和题面/页面摘要，不保存页面写入权限、鉴权网址或题目图片。默认保留 7 天；设置 → AI 与用量可选关闭、1/7/30 天以及清空全部。最多 600 条 / 2 MB，读取或写入时按期限淘汰旧记录。
- 刷新后先识别，显式恢复只还原参考结果，不填写页面，也不继承平台保存状态。继续搜索复用仍有效结果；单题“重新搜本题”强制重新请求。页面与题目内容（含选项顺序/标识）须完全对应，重新编号的控件可能需要重搜；来源配置改变后旧结果仅供查看。本地结果需重新匹配当前库并重建有效凭据。图片题、未识别文字和外部粘贴导入的会话不持久化。
- 恢复后默认只搜题、全部已加载范围，并选择首个尚无有效结果的题目；需要不同范围请重新选择。章节学习的起点/游标仍使用原有独立会话，不因恢复题目记录自动启动。历史参考不等于平台标准答案。
- “AI 用量与预算”显示所有页面共用、本轮自上次重置起的请求数、输入/输出、缓存/思考 Token、已知预计费用、费用未知次数及进行中数量。价格在设置中按当前接口和模型填写（人民币/百万 Token）；不预填可能过期的费率。价格变化明确开始新一轮，旧金额不会按新价格重算；本版不保留多轮账单。
- DeepSeek 官方流式接口请求 include_usage，兼容接口仅统计实际返回的 usage；JSON、SSE、截断回答和失败请求也记录可取得的用量。思考 Token 包含于输出，不重复加算；缓存命中包含于输入。未提供用量、取消或中断且缺最终用量、缺单价都标为费用未知，不能视为免费。依据：[DeepSeek 官方响应字段](https://api-docs.deepseek.com/api/create-chat-completion/)。
- 预算为 0 时关闭。开启后请求前检查已知费用；缺价格、已有未知费用或达到预算会阻止下一次 AI 请求。同一时间只允许一个 AI 请求，避免多标签同时穿过预算。单次已发请求仍可能超出阈值，这不是服务商硬限额；以实际账单为准。连接测试与整卷复检也计入，本地题库不调用 AI，言溪单独收费不计入此统计。后台意外重启遗留的请求转为费用未知；有进行中请求时不能重置或改价。
- 异常卡片区分来源、预算、页面变化、播放受阻、资源未加载和平台待确认，提供重新识别/设置或定位原网页内容入口。浙学同一步骤首次失败后最多再重试 3 次，仍失败则暂停并保留进度；处理后点击继续。可见 iframe/embed/object 只证明阅读器已挂载，无法据此证明跨域阅读内容已经渲染；真实 PDF/PPT 情况仍需实机验证。
- “已获取参考答案”“页面已填写并回读”“平台确认保存/提交”分别显示。独立考试继续停留，不自动翻页、返回或交卷。
## 我的题库

1. 在设置页打开“题库管理”，点击“下载模板”，按 CXQB-1 固定字段准备文件。
2. 选择 TXT、JSON、DOCX、PDF 或 PNG/JPG/WebP。“结构提取”适合 DOCX 和文字 PDF；扫描/混合 PDF 选“本地 OCR”，图片自动选用 OCR；“严格模板”保留旧版单栏文本读取。先显示来源结构/缩略图、提取文本、题目、答案和错误；修正后重新校验，对照来源校对并确认导入。导入不启动答题。
3. 在当前课程的“答题设置 → 本地题库辅助”勾选“先查本地题库”和适用的库，再点击“保存题库选择”。新导入的库不会自动加入已选范围。
4. 选择“仅本地题库”可在没有 API 配置时使用；先“识别当前页”，再选择“只搜题”或“自动填写”并启动。若选择了在线来源，只有另行开启“未匹配时使用所选在线来源”才会在本地未命中后联网。
5. 管理页支持搜索、按题型/冲突筛选、分页查看、重命名、启停、单题/勾选删除和整库删除。可导出模板 TXT 或 JSON 备份；删除需要明确确认，删除后使用原文件或备份恢复。

支持单选、多选、判断、填空、简答的文本模板。题库文件头必须含格式、名称、题目总数，题块使用“【题目】/【结束】”；完整示例可在设置页下载。示例：

```text
题库格式：CXQB-1
题库名称：数据库练习
题目总数：1

【题目】
编号：001
题型：单选
题干：下列哪项是关系数据库管理系统？
选项：
A. MySQL
B. Photoshop
答案：A
解析：MySQL 是关系数据库管理系统。
【结束】
```

多选答案写 `A,C`；判断写“正确”或“错误”；填空提供“空数”，答案逐行写 `1. 内容`、`2. 内容`；简答答案可多行。正文若以保留标签开头，用反斜杠转义，例如 `\答案：题干中的文字`；字面反斜杠写为 `\\`。题干、选项、数字、大小写和公式符号需保持完整。

文件限制：TXT/JSON 5 MiB，文档/图片 20 MiB；PDF 最多 200 页，文字模式每批 200 页，OCR 每批最多 20 页或图片。单张原图不超过 4000 万像素，工作画布约限 1000 万像素；每个识别区域 60 秒超时。总库最多 2000 题及 6 MB 结构化条目。TXT 默认 UTF-8，乱码时可选 GB18030/GBK；旧 DOC 请另存为 DOCX。

“页码、分栏与截取设置”支持 `1-5,8` 页码、自动/按行/先左后右/先右后左读取，以及 `x,y,宽,高` 百分比截取，例如 `0,8,100,84` 去掉上下边缘。手动双栏 OCR 按所选区域中线分割；文字模式依据字符位置分栏。修改设置后需点击“重新读取”；旧预览不能直接提交。最多显示前 20 页来源缩略图。文字模式遇到扫描或图片页会提示切换 OCR，整轮重新读取，不静默丢页；OCR 模式逐页处理整个选区。

DOCX 可提取基本正文/表格、简单字母或数字编号、上下标与分式；含“题型/题干/答案”等字段的表格可整理成 CXQB-1。其他表格、跨表/跨栏/跨页题目仍需人工整理。来源结构预览不等同于 Word 原版排版；复杂公式、嵌入对象和未知图片以待校对占位显示，转写或移除后才能入库。页眉页脚及表格外未合并的内容需对照原文件补齐。

OCR 引擎、WASM 与中英文语言包随扩展离线提供，使用时无需 API Key。读取、识别和校对均在设置页本机完成；关闭设置页或取消会终止 OCR Worker，已入库内容不受影响。OCR 可能把问号、数字、否定词或公式识别错；置信度不是答案正确率。识别结果不会自动变成题库，须整理固定模板、重新校验并勾选来源校对确认。原始文件及来源图片不长期保存，只保存最终题目和答案。离线资源归属、原包元数据和 SHA256 位于 `vendor/ocr/`。

本地匹配要求题型、完整题干和选项/空位结构一致，普通乱序选项按内容映射；包含“以上”“A 和 B”等位置依赖内容时继续严格限制。不同答案的同题记录标为冲突，不自动任选一条。相似题单独展示供人工参考，不产生自动填写凭据。思维阶梯与普通题目共用本地优先来源和选库设置；纯本地命中无需 API。导入/完整匹配表示结构可对应，不代表答案已被平台验证；页面可填写范围继续受现有适配器限制。

题库保存在扩展源 IndexedDB，文件二进制不长期留存，也不上传；旧 JSON 题库首次使用时迁移为“旧版导入题库”。课程选择只保存平台和课程标识，没有课程编号的浙学页面从 0.3.6 起按当前页面路径及试卷标识的摘要分别选库，旧平台通用手动选择需重新勾选，库内容保留；不保存鉴权查询参数。删库、停用、改选或内容变化会取消旧任务/预览并要求重新匹配；页面已有答案不因删除题库而清空。卸载扩展会清除本机数据，更新前建议保留 JSON 备份。

**模板导出再导入**：题目结果区的“导出格式”增加“题库模板 TXT”。需要明确选择使用“已获取答案”还是“当前页面答案”；只导出完整纯文本题目，缺答案、图片、复杂题型会显示跳过数量。AI 复检建议不会自动当作最终答案。该模板可在管理页重新导入；旧阅读版 TXT 和 question-results JSON 仍是查看格式，不能直接当作题库文件。管理页 JSON 备份使用独立的 question-library 格式，旧 bank JSON 入口继续兼容。

## 安全与隐私

- 本机搜题记录默认保留 7 天，可关闭或清空；本地题库、用量与设置保存在扩展存储中。记录不会自动上传。
- API Key 只保存在本机扩展设置，不写入仓库；只有在你配置并主动使用 AI 时，题目才会发送到对应的 AI 接口。
- 不自动交卷，不自动运行程序题代码，不绕过平台限制。
- 扩展重载、后台重启或页面长时间停留可能导致连接断开；刷新页面即可恢复。

## 项目结构

```text
src/
  content/      内容脚本入口（MAIN / ISOLATED）
  background/   后台 Service Worker
  popup/        扩展弹窗
  options/      设置页
  features/     按功能拆分的模块
  shared/       跨模块协议、站点与工具
scripts/        构建、打包与发布脚本
```

代码按功能放在 `src/features/`；入口位于 `src/content/`、`src/background/`、`src/options/` 和 `src/popup/`。
